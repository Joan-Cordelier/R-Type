# Introduction

Bienvenue sur la documentation officielle du projet **R-Type**.

Ce projet a été réalisé dans le cadre du cursus **Epitech**. L'objectif est de développer un moteur de jeu multijoueur performant et modulaire, capable de reproduire le fonctionnement du célèbre jeu d'arcade *R-Type* (1987).

Contrairement à un développement de jeu classique utilisant des moteurs existants (Unity, Unreal), ce projet met l'accent sur l'architecture logicielle bas niveau, la gestion de la mémoire, et la programmation réseau asynchrone en C++.

## Fonctionnalités Clés

* **Moteur de Jeu Custom (ECS)** : Architecture *Entity Component System* développée "from scratch" pour une modularité maximale.
* **Réseau Hybride** : Utilisation conjointe de **TCP** (fiabilité) et **UDP** (performance) pour une expérience multijoueur fluide.
* **Serveur Multithreadé** : Capacité à gérer plusieurs salles (Rooms) et parties simultanées.
