R-Type Documentation

Interface Utilisateur

Ce guide explique comment naviguer dans les différents menus du jeu R-Type.

Lancer le Jeu

Depuis le menu principal, cliquez sur Play pour accéder à l’écran de connexion.

Ecran de Connexion

Connexion / Inscription

  1. Nom d’utilisateur : Tapez votre pseudo
  2. Appuyez sur Tab pour passer au champ mot de passe
  3. Mot de passe : Entrez votre mot de passe
  4. Cliquez sur :
    • Login : Si vous avez déjà un compte
    • Register : Pour créer un nouveau compte

Mode Invité

  • Cliquez sur Guest pour jouer sans compte
  • En mode invité, vous n’aurez pas accès au leaderboard et vos scores ne seront pas sauvegardés

Lobby (Gestion des Salons)

Après connexion, vous arrivez dans le lobby où vous pouvez rejoindre ou créer des parties.

Boutons du Lobby

BoutonAction
LogoutRetourne à l’écran de connexion et vous déconnecte
ChatAffiche ou masque le panneau de chat
Create RoomOuvre le menu de création de salon
RefreshActualise la liste des salons disponibles
ScoreboardAffiche le classement des meilleurs joueurs (mode Endless)

Système de Chat

Le chat peut être affiché ou masqué en cliquant sur le bouton Chat.

Quand le chat est masqué :

  • Un badge rouge apparaît sur le bouton indiquant le nombre de messages non lus
  • Le compteur affiche de 1 à 99, puis 99+ au-delà

Quand le chat est affiché :

  • Appuyez sur T pour activer le champ de saisie
  • Tapez votre message
  • Appuyez sur Entrée pour envoyer le message
  • Appuyez sur Echap pour quitter le champ de saisie sans envoyer

Liste des Salons

La liste affiche les parties en cours avec leurs informations :

  • Nombre de joueurs : Affiché sous forme de ratio (ex: 2/4 signifie 2 joueurs sur 4 places)
  • Cliquez sur Join pour rejoindre un salon
  • Utilisez Refresh pour actualiser la liste

Attention : Un salon vide se ferme automatiquement après 5 secondes. Soyez rapide après avoir créé votre salon !

En Jeu

Une fois dans une partie, vous pouvez interagir avec l’interface de jeu.

Chat en Partie

Le chat fonctionne de la même manière que dans le lobby :

  • Appuyez sur T pour écrire un message
  • Appuyez sur Entrée pour envoyer
  • Appuyez sur Echap pour annuler

Menu Paramètres

Appuyez sur Echap pour ouvrir le menu des paramètres.

Menu Pause

Appuyez sur P pour ouvrir le menu pause.

ATTENTION : Le menu pause ne met pas le jeu en pause. La partie continue pendant que le menu est ouvert.

Le menu pause contient 4 boutons :

BoutonAction
ResumeFerme le menu et reprend le jeu
SettingsOuvre les paramètres
Exit PartyQuitte la partie et retourne au lobby
ExitQuitte complètement le jeu

Pour fermer le menu pause, vous pouvez :

  • Cliquer sur Resume
  • Appuyer sur P
  • Appuyer sur Echap

Ecran de Fin de Partie

Quand vous mourrez ou quand vous gagnez la partie, un écran de fin s’affiche avec :

  • Votre score final de la partie
  • Deux boutons :
    • Return to Lobby : Retourne au lobby pour rejoindre ou créer une nouvelle partie
    • Exit : Quitte complètement le jeu

Avertissements Importants

ATTENTION - Règle du “No Rejoin”

Une fois que vous quittez une partie (que ce soit en mourant, en cliquant sur “Exit Party”, ou en fermant le jeu), vous ne pouvez plus rejoindre cette partie.

Quitter = Game Over définitif pour cette session.

Cela signifie :

  • Si vous mourrez, vous ne pouvez pas revenir dans la partie en cours
  • Si vous retournez au lobby via “Exit Party”, la partie continue sans vous
  • Les autres joueurs continueront sans vous jusqu’à la fin de la partie

Les Modes de Jeu en Détail

Classic

Le mode de jeu principal :

  • 2 niveaux complets
  • Chaque niveau contient plusieurs vagues d’ennemis
  • Un boss apparaît à la fin de chaque niveau
  • Entre les vagues, choisissez des améliorations parmi 3 cartes

Boss Only

Pour ceux qui veulent du défi direct :

  • Passez directement aux combats de boss
  • Aucune vague d’ennemis classiques
  • Idéal pour s’entraîner contre les boss

Endless (Infini)

Le mode compétitif :

  • La partie ne s’arrête jamais
  • Les niveaux se répètent en boucle
  • La difficulté augmente à chaque cycle
  • Vos scores sont enregistrés dans le leaderboard
  • Nécessite un compte pour sauvegarder votre score

Speedy

Une version frénétique :

  • Identique au mode Classic
  • Tout est plus rapide (ennemis, projectiles, spawn)
  • Pour les joueurs expérimentés

Scoreboard

Le tableau des scores affiche les classements du mode Endless :

  • Accessible uniquement avec un compte
  • Classement par difficulté
  • Affiche le pseudo, le score et le nombre de cycles complétés
